# SI equation and metric archive

The repository has **146 pandas PKL files** containing the equations and
performance metrics behind SI Sections S4.2.1--S4.2.4 and S5:

| Folder | Files | Models |
| --- | ---: | --- |
| `LINEAR_NEUTRAL` | 36 | Neutral-only CATMAP linear fits |
| `LINEAR_ALL_CHARGES` | 36 | Full-dataset CATMAP linear fits |
| `NONLINEAR_NEUTRAL` | 36 | Neutral-only SyMANTIC fits |
| `NONLINEAR_ALL_CHARGES` | 36 | Full-dataset SyMANTIC fits |
| `BEP_NEUTRAL` | 1 | Neutral-only BEP fits for all four TSs |
| `BEP_ALL_CHARGES` | 1 | Full-dataset BEP fits for all four TSs |

Each two-descriptor file is named `RESULTS_<DESCRIPTOR_1>_<DESCRIPTOR_2>.PKL`.
For example, `LINEAR_NEUTRAL/RESULTS_CH_HCO.PKL` has 11 target rows plus
pooled rows for all targets, adsorbates only, and TSs only. Each BEP folder
has `RESULTS_ALL.PKL`, with four TS rows and one pooled TS row. Read a file
with pandas:

```python
import pandas as pd
results = pd.read_pickle("LINEAR_NEUTRAL/RESULTS_CH_HCO.PKL")
print(results[["TARGET", "EQUATION", "FIT_R2", "FIT_RMSE_EV", "LOMO_RMSE_EV"]])
```

`EQUATION` is a LaTeX expression with the actual adsorption- or
activation-energy symbols and full-precision fitted coefficients.
`COMPLEXITY` reproduces the SI's $C_x$ column for the two-descriptor models.
`PREFERRED_CRITERIA_MET` is populated for all-charge SyMANTIC rows; `False`
corresponds to the dagger in the SI tables. `FIT_R2` is the coefficient of
determination. RMSE values are in eV. For two-descriptor fits,
`LOMO_RMSE_EV` is **nested** leave-one-metal-out RMSE, with equation selection
and fitting repeated inside each fold. BEP always has the same linear form,
so its LOMO refits the slope and intercept inside each fold. A pooled row has
no equation or $R^2$; its RMSE weights each target by its number of
observations.

The PKLs were assembled from the saved full-precision fitting results used to
make the SI. In particular, the neutral SyMANTIC PKLs combine the selected
full-data equations with the later **nested** LOMO scores. The earlier
fixed-form LOMO column in its equation CSV is not used. For full-dataset
SyMANTIC, the PKLs use the consolidated selected-equation and grouped LOMO
results. The two BEP PKLs are regenerated by `BEP_COMMON.PY` and use the
HO--H reaction-energy direction reported in the SI.

`EXPORT_SI_RESULT_PKLS.PY` recreates the archive from those saved analysis
CSVs. It accepts `--source-root` to identify the original `SR` work folder.
The exporter expects those source CSVs; the four fitting scripts and two BEP
scripts can separately regenerate results from the energy pickle. All 1,584
two-descriptor target metrics and criterion markers were checked against the
current SI tables. All archived equations were evaluated against the original
energies and reproduce their saved fit RMSEs to numerical precision.
